# copilot_research

Microsoft 365 Copilot を中心とした調査結果を、Markdown ドキュメントとして管理するリポジトリです。

## ドキュメント一覧
- [Microsoft 365 Copilot：ファイル／ドキュメント読み込みの制約に関する調査レポート（2026年9月15日時点）](docs/reports/microsoft-365-copilot-file-document-limits-2026-09-15.md)

## 要約
- Microsoft 365 Copilot では、文書要約・参照は約80,000語以下、Q&Aは約7,500語以下、書き換えは約3,000語以下が公式ガイダンスとして示されている
- 長い文書ではエラーにならず、先頭優先で中盤以降が無視される場合があるため、要約用途では文書分割や論点整理が重要になる
- ファイルサイズ上限は製品ごとに異なり、コンシューマー版 Copilot は 1ファイル50MB・1会話20ファイル、SharePoint 参照は条件により 7MB または 200MB、Copilot Studio の直接アップロードは 512MB/ファイル
- 業務用 Microsoft 365 Copilot Chat のファイル上限やコンテキストウィンドウは、公式に明示されていない数値も多く、非公式情報との切り分けが必要

## 方針
- プログラム開発ではなく、調査結果・ナレッジ・レポートを Markdown で管理する
- 調査テーマごとに `docs/` 配下へ文書を追加する
- 必要に応じて一次情報への参照を文書内に明記する
